# GameZone Rental PS

## Deskripsi
GameZone Rental PS adalah aplikasi console berbasis Java untuk menghitung biaya penyewaan PlayStation 4 dan PlayStation 5.

## Fitur
- Input nama pelanggan
- Pilihan konsol PS4 dan PS5
- Perhitungan biaya sewa
- Diskon 10% untuk penyewaan minimal 3 jam
- Tambahan minuman opsional
- Cetak struk pembayaran
- Transaksi berulang

## Teknologi
- Java
- Apache NetBeans IDE
- JDK 26

## Cara Menjalankan
1. Buka proyek GameZoneRentalPS di Apache NetBeans IDE.
2. Buka file GameZoneRentalPS.java.
3. Jalankan program menggunakan Run File.
4. Masukkan data sesuai petunjuk pada console.
